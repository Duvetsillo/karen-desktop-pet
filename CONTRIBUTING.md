# Contribuir

Usa Node 24 y `npm ci`. Ejecuta `npm run typecheck`, `npm test` y `npm run build`.
El cliente Windows requiere Windows 11; el servidor Node y las pruebas de contrato
funcionan sin Electron ni un Gateway real.

Crea una rama por cambio y una pull request con un problema concreto, explicación,
pruebas y límites. Se aceptan mejoras de accesibilidad, rendimiento, pruebas,
adaptadores y documentación. No incluyas actividad artificial para incrementar
estadísticas ni propuestas sin una mejora verificable.

Las revisiones deben comprobar el comportamiento y señalar ubicaciones concretas.
Identifica si una revisión es automatizada. No apruebes cambios sin comprobarlos.
No mezcles secretos o datos privados en ejemplos, capturas o reportes. Usa una
cuenta de Git con correo noreply si quieres evitar publicar tu correo personal.

Los cambios se distribuyen bajo la licencia MIT del repositorio.
